Multi-Platform App (Android • iOS • Windows • Mac)

Instal Aplikasi di HP & Laptop Anda

Aplikasi ini telah dilengkapi teknologi Progressive Web App (PWA) & penyimpanan lokal permanen. Pasang ikon aplikasi ke layar utama HP atau Desktop Laptop agar bisa dibuka layar penuh seperti aplikasi native.

HP Android (Chrome)

Klik tombol "Instal Aplikasi Sekarang" atau ketuk titik tiga (⋮) di pojok kanan atas Chrome → pilih "Instal aplikasi / Tambahkan ke layar utama".

iPhone / iPad (Safari)

Buka di browser Safari → ketuk ikon Bagikan (Share ↑) di bagian bawah → pilih "Tambah ke Layar Utama (Add to Home Screen)".

Laptop Windows / Mac

Buka di Google Chrome / Microsoft Edge → klik ikon Instal () di ujung kanan bilah alamat URL atau klik tombol instal di atas.

Cara Online-kan Web Permanen

Unduh file .html di atas, ubah namanya menjadi index.html, lalu seret (drag & drop) ke app.netlify.com/drop atau tiiny.host agar mendapat URL online gratis selamanya.
